# План учебного React-проекта (2–3 месяца, ~2–4 ч/нед)

Уровень: новичок в JS, базовый React уже знаком. Формат: репозиторий у тебя, однокурсница форкает и шлёт PR.

## Настройка GitHub (сделать один раз в начале)

1. Создаёшь репозиторий на своём аккаунте (Vite + React).
2. В Settings → Branches включаешь защиту `main`: запрет прямого пуша, обязательный PR + review.
3. Добавляешь `CONTRIBUTING.md`: как форкнуть, клонировать форк, создать ветку, запушить, открыть PR.
4. Заводишь Issues на каждую задачу ниже — она берёт issue, делает ветку `feature/название`, открывает PR со ссылкой `Closes #N`.
5. Шаблон PR (`.github/pull_request_template.md`): что сделано / как проверить / скриншот.

## Неделя 1 — Проект 1: Счётчик + переключатель темы
Концепции: useState, обработчики событий, условный рендеринг.

- PR1: каркас проекта (Vite, структура папок, деплой на Vercel/Netlify)
- PR2: счётчик (+/-/сброс)
- PR3: переключатель светлой/тёмной темы

## Недели 2–3 — Проект 2: To-Do лист
Концепции: массивы в стейте, controlled inputs, localStorage.

- PR1: рендер статичного списка задач
- PR2: добавление задачи через форму
- PR3: удаление и отметка "выполнено"
- PR4: сохранение в localStorage

## Недели 4–5 — Проект 3: Поиск по API (погода или фильмы)
Концепции: useEffect, fetch/axios, async, loading/error state.

- PR1: статичная вёрстка (поле поиска + карточки-заглушки)
- PR2: запрос к API при загрузке страницы
- PR3: поиск по запросу пользователя
- PR4: обработка загрузки и ошибок (спиннер, сообщение об ошибке)

## Неделя 6 — Проект 4: Квиз / флеш-карты
Концепции: useReducer, вложенные компоненты, пропсы, таймер.

- PR1: структура данных вопросов + рендер вопроса
- PR2: подсчёт очков через useReducer
- PR3: таймер на вопрос

## Недели 7–8 — Проект 5: Каталог с роутингом
Концепции: React Router, динамические параметры URL.

- PR1: настройка роутера, страница списка (книги/фильмы/рецепты)
- PR2: страница деталей по клику (`/item/:id`)
- PR3: 404-страница и навигация между разделами

## Недели 9–10 — Проект 6: Форма + Context API
Концепции: валидация форм, глобальный стейт через Context.

- PR1: форма с валидацией (регистрация или создание записи)
- PR2: Context для темы или "пользователя" на весь проект
- PR3: объединение формы и контекста в общий флоу

## Недели 11–12 — Финальный мини-проект
Трекер привычек / финансов / рецептов — собрать всё вместе.

- PR1: CRUD базовой сущности (создание, чтение)
- PR2: редактирование и удаление
- PR3: кастомный хук (например `useLocalStorage`)
- PR4 (опционально): пара тестов на React Testing Library

## Как ревьюить PR

- Проверяй не только "работает ли", но и структуру компонентов, именование, лишние ре-рендеры.
- Оставляй комментарии к строкам кода, а не только общий вердикт.
- Если что-то некритично — помечай как `nit:`, чтобы не блокировать мерж по мелочам.
- Мерж — `squash and merge`, чтобы история в `main` была чистой (один коммит на фичу).
