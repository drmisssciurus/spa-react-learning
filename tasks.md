Реализованные фичи
Навигация / Layout (AppLayout.tsx)

Шапка с заголовком и описанием архива
Переключение между разделами: Characters / Spells (кнопки-табы)
Счётчики избранного в шапке (❤ Favorite wizards / ❤ Favorite spells) — по клику переходят на соответствующую страницу избранного
Волшебники (Wizards.tsx, WizardCard.tsx)

Загрузка списка персонажей с API hp-api.onrender.com/api/characters
Состояния loading / error при запросе
Карточка персонажа: имя, species, цвет глаз, факультет (house), происхождение крови (ancestry), patronus, изображение (с фолбэком на "unknown.png", если фото нет)
Кнопка добавления/удаления в избранное (❤/❤ toggle)
Заклинания (Spells.tsx, SpellCard.tsx)

Загрузка списка заклинаний с API /api/spells
Состояния loading / error
Карточка заклинания: имя + описание
Toggle в избранное, аналогично волшебникам
Избранное (FavoriteWizards.tsx, FavoriteSpells.tsx)

Отдельные страницы избранных волшебников и избранных заклинаний, переиспользуют те же карточки
Персистентность в localStorage (ключи hp_favorite_wizards, hp_favorite_spells), синхронизация через useEffect в App.tsx
API-слой (hpApi.ts)

getWizardsInfo(), getSpellsInfo() — обёртки над fetch с обработкой ошибок ответа
Типизация (types.ts)

AppPage, WizardInfo, SpellInfo
